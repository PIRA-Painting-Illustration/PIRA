# PIRA brand (working)

**PIRA — Painting, Illustration & Raster Art.** Tagline: *Create · Explore · Share · Belong.*
Secondary lines: "Art Without Limits", "Create Freely. Share Openly."

The logo is being drawn by the project owner. `brand-concept.webp` is an AI-generated concept
board for direction only: it is not the logo and none of its artwork ships in the app. The icon
in `assets/app-icon/hicolor/` is a placeholder (`tools/pira-icon/make_icon.py`).

## Palette

| Token | Hex | In the PIRA theme |
|---|---|---|
| Deep teal-navy | `#0F1E25` | Base surface; text on coral buttons |
| Teal | `#2A9D8F` | Accent: selection, focus, toggles |
| Coral | `#FF6B5A` | Primary buttons, close button, danger |
| Sun yellow | `#FFD166` | Warnings |
| Violet | `#7B61FF` | Icon stroke gradient (spare accent) |
| Cream | `#EDE7D9` | Body text (dark); surfaces (PIRA Light) |

## Type

Concept fonts: Montserrat (primary) and Sora (accent), both SIL OFL. Not bundled yet: the port's
rule is that font files live outside the repository (craft-fonts, `CRAFT_FONTS_DIR`). Until then
the UI uses the built-in Inter.

## Trade dress

Take workflow ideas from painting apps (Clip Studio Paint, Procreate, Krita), never their
artwork, icons, names, layouts copied one to one, or brush files. Our preset names are generic
(HB Pencil, Inking Pen, Brush Pen…), not another app's product names.
