PIRA is a free painting app for pen tablets that works offline. Pencils, inks and paints respond to pen pressure and tilt as soon as it's installed. You don't need an account, a subscription or an internet connection to draw, save or export.

It has layers, masks, adjustment layers, layer styles, text and vector shapes, opens and saves layered PSD files, and has a 3D layer with posable mannequins for reference. PIRA is an early release: expect rough edges, and keep copies of work that matters.

## Built on PhotoCraft

PIRA is an independent project built on [PhotoCraft](https://github.com/storytold/photocraft) by the ArtCraft contributors. It is not made or supported by the PhotoCraft developers or ArtCraft, so please report PIRA problems to PIRA, not to them.

## Get help

Open an issue in the [issue tracker](https://github.com/PIRA-Painting-Illustration/PIRA/issues). In PIRA, **Help › Report an Issue…** opens the same issue tracker.
